# Soft Storefront Style

Diseñá una identidad visual completa y una página web de ecommerce para una marca de papelería creativa que vende productos físicos: agendas, planners semanales y mensuales, blocks de notas, checklists para estudiantes, planificadores docentes, listas de compras y organizadores.

Concepto de marca: papelería creativa, delicada, moderna y funcional. La marca está dirigida principalmente a estudiantes y docentes, aunque también debe resultar atractiva para jóvenes adultos y profesionales. Debe transmitir creatividad, organización, calidez y calidad, sin parecer infantil ni excesivamente formal.

ESTÉTICA VISUAL

Utilizar un estilo editorial contemporáneo combinado con minimalismo cálido, diseño escandinavo y elementos gráficos delicados. La estética debe sentirse cuidada, armoniosa, fresca y comercialmente atractiva. Evitar el minimalismo beige genérico y los diseños demasiado recargados.

PALETA DE COLORES PASTEL

- Marfil cálido: #F8F1E7, para fondos principales.
- Verde salvia: #C5D4C2.
- Azul pastel: #C9D9ED.
- Lila suave: #D9CBEA.
- Rosa empolvado: #F1C9C5.
- Amarillo pastel: #F3DFA6.
- Grafito suave: #41413E, para textos y elementos de lectura.

Todos los colores deben ser suaves, apagados y armoniosos. No utilizar colores vibrantes, neón, saturados ni contrastes estridentes. El marfil debe predominar y los pasteles deben utilizarse para diferenciar productos, categorías y detalles.

TIPOGRAFÍAS

Utilizar DM Serif Display para titulares y frases destacadas, combinada con Nunito Sans para textos, precios, navegación y botones. La jerarquía tipográfica debe ser clara, elegante y legible. Evitar tipografías infantiles o manuscritas como recurso principal.

RECURSOS GRÁFICOS

Incorporar pequeñas estrellas, corazones lineales, flores simples, líneas onduladas, cuadrículas, etiquetas y formas geométricas redondeadas. Los elementos deben ser discretos, consistentes y secundarios respecto de los productos. Utilizar ilustraciones lineales delicadas y pequeños detalles gráficos que aporten personalidad sin saturar el diseño.

ESTILO FOTOGRÁFICO

Fotografía editorial de producto con luz natural, sombras suaves, fondos marfil, papel texturado y composiciones cuidadas. Mostrar agendas cerradas y abiertas, interiores reales, encuadernaciones, blocks, lápices y materiales de estudio. Incorporar escenas de escritorio y materiales docentes. Los productos deben ser los protagonistas y sus colores deben coincidir con la paleta de marca. Evitar imágenes artificiales, brillos excesivos, fondos vibrantes y composiciones recargadas.

DISEÑO DE LA PÁGINA WEB

Crear una tienda online completa, visualmente coherente, responsive y optimizada para celulares.

1. Encabezado con logotipo, menú, buscador, cuenta y carrito.
2. Portada principal con una fotografía atractiva de agendas y papelería pastel, el titular «Organizá tu día, seguí tus sueños», una breve descripción y un botón «Ver productos».
3. Categorías visuales con tarjetas para agendas y planners, estudio, docentes, blocks de notas y listas organizadoras.
4. Sección de productos más vendidos con fotografías, nombres, precios, variantes y botones de compra.
5. Banner editorial para promocionar combos de estudio y organización.
6. Sección de colecciones diferenciadas por uso y necesidad.
7. Beneficios de compra: medios de pago, envíos y atención personalizada, sin inventar condiciones comerciales.
8. Opiniones de clientes únicamente si existen reseñas reales.
9. Newsletter y pie de página con contacto, preguntas frecuentes, políticas de compra y redes sociales.

DISEÑO DE PRODUCTOS

La estética de la web debe extenderse a las portadas y al packaging. Diseñar agendas, planners y blocks con fondos pastel, composiciones tipográficas elegantes, títulos legibles y detalles gráficos pequeños. Cada producto debe tener una identidad propia dentro de un sistema visual consistente.

RESULTADO ESPERADO

Presentar una propuesta visual profesional de la marca y un mockup detallado de la página de inicio, mostrando claramente la paleta, las tipografías, las fotografías, las categorías y las tarjetas de producto. La web debe parecer una tienda real de papelería de diseño, lista para inspirar una implementación comercial, no una plantilla genérica.

Priorizar la coherencia visual, la legibilidad, la navegación intuitiva y la presentación atractiva de los productos. Mantener una estética pastel suave en todos los elementos, sin incorporar colores vibrantes ni modificar la dirección de arte establecida.
